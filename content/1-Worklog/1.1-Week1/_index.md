### Week 1 Objectives:

* Learn Cloud Computing fundamentals and the AWS Global Infrastructure model.
* Register an AWS Free Tier account and set up essential account security measures.
* Configure basic AWS IAM (Identity and Access Management) resources (Users, Groups, Policies).
* Install and test the AWS CLI on the local machine.

### Week 1 Achievements:

* Understood core cloud computing concepts and AWS Global Infrastructure.
* Secured the AWS account with MFA and configured AWS Budget notifications.
* Set up an IAM User for daily administrative work instead of using the Root Account.
* Installed and verified AWS CLI configuration locally.
