### Week 4 Objectives:

* Understand Amazon S3 (Simple Storage Service) object storage fundamentals.
* Practice creating S3 Buckets, uploading/downloading objects, and configuring object permissions.
* Enable S3 Static Website Hosting to host static HTML/CSS/JS web applications.
* Explore S3 Versioning, Bucket Policies, CORS, and Lifecycle Rules.

### Week 4 Achievements:

* Understood Amazon S3 object storage management and configuration.
* Successfully hosted a static website on Amazon S3 at minimal cost.
* Configured S3 Bucket Policies and CORS access rules.
* Applied S3 Lifecycle Rules for automated long-term storage cost optimization.
