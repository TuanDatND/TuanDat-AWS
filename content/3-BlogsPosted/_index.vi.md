Tại đây sẽ là phần liệt kê, giới thiệu các blogs mà các bạn đã đăng trên [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj). Ví dụ:

###  [Blog 1 - Xây dựng REST API Multi-Region với Aurora DSQL](3.1-Blog1/)
Bài viết này chia sẻ giải pháp kết hợp Spring Boot và Amazon Aurora DSQL để xây dựng REST API Multi-Region hoạt động song song (active-active) không bị đụng độ dữ liệu, tự động xác thực IAM bằng DsqlConnector và tối ưu hóa kết nối cơ sở dữ liệu với Spring Retry.

###  [Blog 2 - Kiro Steering Files và bảo mật AWS](3.2-Blog2/)
Bài viết phân tích cách sử dụng Kiro Steering Files để cung cấp ngữ cảnh bảo mật lâu dài cho các trợ lý AI (như Amazon Q) trên AWS. Giải pháp này giúp AI tự động tạo tài nguyên tuân thủ nghiêm ngặt các quy tắc bảo mật (như mã hóa mặc định, chặn public access) của doanh nghiệp ngay từ đầu.

###  [Blog 3 - DDoS Visibility với AWS Shield Advanced Flow Logs](3.3-Blog3/)
Bài viết đi sâu bóc tách kỹ thuật về tính năng attack flow logs của AWS Shield Advanced. Cung cấp chi tiết về cấu trúc log record, mô hình kiến trúc phân phối phi tập trung (S3, CloudWatch Logs, Firehose) và hướng dẫn triển khai cấu hình chi tiết qua AWS CLI.
